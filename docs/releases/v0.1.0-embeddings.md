## Precomputed Qwen retrieval index

**Use the latest `main` source, not this release's automatic Source code ZIP.**
The `v0.1.0-embeddings` tag predates the index import tool.

- [Download index ZIP](https://github.com/user-attachments/files/34176724/warhammer-qwen-parent-child-index-20261030.zip)
- [SHA-256 checksum](https://raw.githubusercontent.com/AnningMa/warhammer-agent/main/docs/releases/warhammer-qwen-parent-child-index-20261030.zip.sha256)
- [Setup instructions](https://github.com/AnningMa/warhammer-agent#run-the-project)

The package contains 228 parent rules and 237 child vectors of 768 dimensions.
It does not include Qwen model weights or an API key. Qwen is still needed for
query encoding; Gemini is used for routing, refinement, SQL and answers.

### Setup

```bash
git clone https://github.com/AnningMa/warhammer-agent.git
cd warhammer-agent
uv sync --locked --extra agent --extra qwen --extra chroma --extra gemini --extra ui
mkdir -p storage/releases
```

Save the downloaded index ZIP in `storage/releases/`, then run:

```bash
(cd storage/releases && sha256sum -c ../../docs/releases/warhammer-qwen-parent-child-index-20261030.zip.sha256)
.venv/bin/python scripts/index_package.py validate \
  --archive storage/releases/warhammer-qwen-parent-child-index-20261030.zip
.venv/bin/python scripts/index_package.py import \
  --archive storage/releases/warhammer-qwen-parent-child-index-20261030.zip
uv run --locked --extra qwen --extra chroma \
  python scripts/embed_parent_child.py --query "How does Deep Strike work?" --top-k 1
uv run --locked --extra agent --extra qwen --extra chroma --extra gemini --extra ui \
  streamlit run scripts/chat_app.py
```

Enter your own Google AI Studio API key in the sidebar. Validation and import
make no model/API requests; document embeddings do not need rebuilding.
